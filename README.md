# Algorithm and Data Structure Practice

This repository contains my solutions and practice implementations for coding-interview problems. The exercises are primarily based on:

- *Coding Interview Patterns* by Alex Xu
- *Beyond Cracking the Coding Interview*

The problems are organized by data structure or algorithmic pattern, including dynamic arrays, two pointers, binary search, sets and maps, stacks and queues, recursion, linked lists, trees, graphs, heaps, sliding windows, backtracking, dynamic programming, greedy algorithms, topological sort, and prefix sums.

Most exercises include implementations in both Python and C++.

## Running a solution

### Python

```bash
python3 path/to/problem.py
```

### C++

Compile a solution with C++17, then run the generated executable:

```bash
clang++ -std=c++17 -I/opt/homebrew/include path/to/problem.cpp -o problem
./problem
```

## Repository structure

Top-level directories are numbered and named after the topic they cover. Files generally follow this convention:

- `*.py`: Python solution
- `*.cpp`: C++ solution
- `*_sample.cpp`: sample or reference C++ implementation

This is a personal study repository and is not affiliated with the authors or publishers of the referenced books.
